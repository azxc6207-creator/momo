# 台灣麻將計台器

依台灣 16 張麻將規則的計台、連莊、金額結算工具（Streamlit，手機優先）。

## 功能
- **玩家名單**：在「設定」分頁輸入玩家名稱，開新牌局時用下拉選單選人
- **開新牌局視窗**：獨立的彈出視窗，依桌上位置（下／右／上／左）選玩家與起莊
- **十字座位**：牌局畫面以十字排列座位，每格顯示門風（東南西北）、莊／連莊與目前積分
- **點選玩家記錄**：點玩家 → 選「自摸」或「胡牌（胡誰的）」→ 選牌型 → 確認
- **改錯**：「復原」取消上一筆；結算時可「手動修改金額」；「調整積分」直接增減任一玩家積分
- **換座位**：可重新安排四個位置，積分與歷史紀錄跟著玩家走
- **Google 試算表自動存檔**：每次操作自動存，關掉網頁再開會自動載回（需先完成下方設定）
- 底／台、莊家身分台、每次連莊加幾台、連莊上限、流局是否連莊皆可自訂；台數表可直接編輯
- 每把紀錄、CSV 匯出、JSON 存檔與載入；「結束牌局」後可還原上一局

## 座位與輪莊
座位編號即輪莊順序，畫面位置依真實牌桌逆時針：**下 → 右 → 上 → 左**。
換莊時依此順序換到下一位；每位玩家方塊上的東／南／西／北是該玩家目前的門風（莊家為東）。

## 結算規則
- 每家應付 = 底 + 台數 × 每台
- 台數 = 牌型台數 + （莊家參與時）莊家身分台 + 連莊數 × 每次連莊台數
- 自摸：三家各付；放槍：放槍者一人付
- 非莊家自摸時，只有莊家多付莊家加成
- 莊家胡牌：連莊數 +1；他人胡牌：換莊、連莊歸零
- 手動修改金額只覆蓋該付款人的金額，莊家與連莊的推進仍照規則
- 尚未支援：一炮多響（目前一把一位胡牌者）

## 本機執行
```bash
pip install -r requirements.txt
streamlit run app.py
```
沒有設定 Google 試算表時，app 照常運作，只是資料不會自動保存。

## 測試
```bash
pip install pytest
pytest -q
```

## 部署到 Streamlit Cloud
1. 在 GitHub 建立新 repository，把本資料夾所有檔案上傳
   （`app.py`、`mahjong_core.py`、`cloud_store.py`、`requirements.txt`、`.gitignore`、`README.md`；
   `secrets.toml.example` 可一併上傳，裡面只有範例沒有真金鑰）。
2. 前往 https://share.streamlit.io 以 GitHub 帳號登入。
3. 點 **Create app** → 選擇該 repository 與分支，Main file path 填 `app.py`。
4. 點 **Deploy**。要啟用自動存檔，接著做下一節的 Secrets 設定。

## 設定 Google 試算表自動存檔（一次性）
1. 到 [Google Cloud Console](https://console.cloud.google.com/) 建立專案（或用既有專案），
   在「API 和服務」→「程式庫」啟用 **Google Sheets API**。
2. 「IAM 與管理」→「服務帳戶」→ 建立服務帳戶 → 進入該帳戶的「金鑰」分頁 →
   新增金鑰 → **JSON**，下載金鑰檔。
3. 在 Google 試算表新建一份空白試算表，按「共用」，把服務帳戶的 email
   （金鑰檔裡的 `client_email`）加為**編輯者**。
4. 打開 Streamlit Cloud 的 App → Settings → **Secrets**，照 `secrets.toml.example`
   貼上：試算表網址，以及金鑰檔裡的各欄位。`private_key` 內的換行要保留成 `\n`。
5. 儲存後 app 會重新啟動。畫面最上方出現「☁️ 已自動存到 Google 試算表」就成功了。

試算表裡會出現兩個分頁：
- `mahjong_state`：app 自動讀寫的資料，請不要手動修改。
- `牌局紀錄`：每把輸贏與累計積分的表，方便你直接查看。這一頁只是輸出，
  在試算表裡修改不會回到 app。

注意事項：
- 金鑰檔等同密碼，不要放進 GitHub、不要貼到聊天或公開的地方；這份試算表也不要公開分享。
- 設計給一個人記帳。同時開兩個網頁（例如手機和電腦）時，後操作的會蓋掉先操作的，
  而且只有開啟網頁的那一刻會從雲端載入。
- 讀取雲端失敗時（網路問題、金鑰錯誤）app 會停止存檔並顯示原因，避免把空資料蓋掉雲端；
  修好後按「重新連線雲端」。
- 沒有網路時無法存檔；請到「紀錄」分頁下載 JSON 當備份。

## 限制
- 十字座位在手機上是靠自訂 CSS 讓欄位維持橫向並排，若日後 Streamlit 改版，
  版面可能需要微調。
