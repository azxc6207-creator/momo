# 台灣麻將計台器

依台灣 16 張麻將規則的計台、連莊、金額結算工具（Streamlit，手機優先）。

## 畫面與功能
- **目前牌局**：標題顯示「牌局編號、第幾將、圈風與莊位風、第幾局」；
  十字座位卡片顯示姓名、積分（贏綠輸紅）與「摸／胡／槍」次數，莊家有紅框與「🔴莊」標記；
  中央是圈風與「流局」鈕，左下角「顯示模式」可切換「累計」或「本將」。
- **點選玩家記錄**：點玩家 → 選「自摸」或「胡牌（別人放槍）」→ 選放槍者與牌型 → 確認。
  結算時可「手動修改金額」。
- **工具列**：復原操作、調整分數、統計/結算、旋轉視角、調整位置。
  - 旋轉視角：只改變畫面上的座位方向（讓自己坐在下方），不影響輪莊。
  - 調整位置：先點一位、再點另一位互換座位，積分與紀錄跟著玩家走。
  - 統計/結算：列出各家積分與「最少轉帳」的結算方式，並可結束牌局（歸檔）。
- **牌局紀錄**：進行中牌局的每把紀錄（可下載 CSV），以及過去已結束的牌局，可「繼續這局」或刪除。
- **數據統計**：每位玩家的自摸／胡牌／放槍次數與金額、被自摸金額、胡牌率與放槍率、積分走勢圖；
  可切換「累計」或「本將」。
- **設定**：玩家名單、底與台、莊家與連莊規則、台數表、JSON 備份與載入。
- **選單**：所有選擇都是「點開才出現一排按鈕」的折疊式，不使用下拉選單。
- **Google 試算表自動存檔**：每次操作自動存，關掉網頁再開會自動載回（需先完成下方設定）。

### 名詞
- 摸＝自摸；胡＝別人放槍給你胡牌；槍＝你放槍給別人胡牌。
- 一「將」＝東南西北四圈（16 局）。北圈結束後進入下一將，「本將」只計算目前這一將的積分與戰績。
- 圈風＝目前是哪一圈（東南西北）；莊位風＝本圈第幾位莊家。

## 座位與輪莊
座位編號即輪莊順序，畫面位置依真實牌桌逆時針：**下 → 右 → 上 → 左**。
換莊時依此順序換到下一位；結算與統計中的「門風」以莊家為東。

## 結算規則
- 每家應付 = 底 + 台數 × 每台
- 台數 = 牌型台數 + （莊家參與時）莊家身分台 + 連莊數 × 每次連莊台數
- 自摸：三家各付；放槍：放槍者一人付
- 非莊家自摸時，只有莊家多付莊家加成
- 莊家胡牌：連莊數 +1；他人胡牌：換莊、連莊歸零
- 手動修改金額只覆蓋該付款人的金額，莊家與連莊的推進仍照規則
- 尚未支援：一炮多響（目前一把一位胡牌者）

## 本機執行
```bash
pip install -r requirements.txt
streamlit run app.py
```
沒有設定 Google 試算表時，app 照常運作，只是資料不會自動保存。

## 測試
```bash
pip install pytest
pytest -q
```

## 部署到 Streamlit Cloud
1. 在 GitHub 建立新 repository，把本資料夾所有檔案上傳
   （`app.py`、`mahjong_core.py`、`cloud_store.py`、`requirements.txt`、`.gitignore`、`README.md`、
   `.streamlit/config.toml`；`secrets.toml.example` 可一併上傳，裡面只有範例沒有真金鑰）。
2. 前往 https://share.streamlit.io 以 GitHub 帳號登入。
3. 點 **Create app** → 選擇該 repository 與分支，Main file path 填 `app.py`。
4. 點 **Deploy**。要啟用自動存檔，接著做下一節的 Secrets 設定。

## 設定 Google 試算表自動存檔（一次性）
1. 到 [Google Cloud Console](https://console.cloud.google.com/) 建立專案（或用既有專案），
   在「API 和服務」→「程式庫」啟用 **Google Sheets API**。
2. 「IAM 與管理」→「服務帳戶」→ 建立服務帳戶 → 進入該帳戶的「金鑰」分頁 →
   新增金鑰 → **JSON**，下載金鑰檔。
3. 在 Google 試算表新建一份空白試算表，按「共用」，把服務帳戶的 email
   （金鑰檔裡的 `client_email`）加為**編輯者**。
4. 打開 Streamlit Cloud 的 App → Settings → **Secrets**，照 `secrets.toml.example`
   貼上：試算表網址，以及金鑰檔裡的各欄位。`private_key` 內的換行要保留成 `\n`。
5. 儲存後 app 會重新啟動。畫面最上方出現「☁️ 已自動存到 Google 試算表」就成功了。

試算表裡會出現兩個分頁：
- `mahjong_state`：app 自動讀寫的資料（進行中牌局、過去牌局、玩家名單、規則、台數表），請不要手動修改。
- `牌局紀錄`：進行中牌局每把的輸贏與累計積分，方便你直接查看。這一頁只是輸出，
  在試算表裡修改不會回到 app。

注意事項：
- 金鑰檔等同密碼，不要放進 GitHub、不要貼到聊天或公開的地方；這份試算表也不要公開分享。
- 設計給一個人記帳。同時開兩個網頁（例如手機和電腦）時，後操作的會蓋掉先操作的，
  而且只有開啟網頁的那一刻會從雲端載入。
- 讀取雲端失敗時（網路問題、金鑰錯誤）app 會停止存檔並顯示原因，避免把空資料蓋掉雲端；
  修好後按「重新連線雲端」。
- 沒有網路時無法存檔；請到「設定」分頁下載 JSON 當備份。

## 限制
- 十字座位在手機上是靠自訂 CSS 讓欄位維持橫向並排，卡片內的換行與大字也是用 CSS 調整，
  若日後 Streamlit 改版，版面可能需要微調。
- 折疊式選單使用 `st.pills`，需要 Streamlit 1.40 以上。
